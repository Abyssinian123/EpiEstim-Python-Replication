### 序列间隔参数(不是文件,但复现必须)

- 流感:parametric_si,mean_si=3.6,sd_si=1.6(Cowling 2009)
- 新冠:parametric_si,mean_si=6.3,sd_si=4.2(Bi et al. 2020,深圳 391 例)
- 先验:Gamma(shape=1, scale=5)= EpiEstim 默认(R\* 与 Rt 同)
- ⚠ EM 内部 R\*→r 反演所用的 SI 离散化与后验 SI 不同,见
  [CONVENTIONS.md §3](CONVENTIONS.md)

## 三、如何运行复现(R 版 / Python 版)

**Python 版(本仓库主推,无需 R)**:

```bash
pip install -r requirements.txt
cd experiments/replication
python reproduce_paper.py     # 论文主图 Fig 2-4 -> ../../results/figures/
python sim_study.py           # S1 附录全部模拟研究 + 其余补充分析(25 张图)
```

**R 版(原始流程,可选)**:

1. 安装 R + RStudio;`install.packages('EpiEstim', repos = c('https://mrc-ide.r-universe.dev', 'https://cloud.r-project.org'))`(需 ≥ 2.4);另需 projections、distcrete、incidence、ggplot2、dplyr、scales、hrbrthemes、cowplot 等(各脚本头部有完整清单);
2. 在 `EM_EpiEstim_Nash2023-main/` 下按 README 顺序运行 `main_analysis/flu.R` → `covid_cases.R` → `covid_deaths.R`,结果与 `figures/` 中 PDF 比对;
3. 用法要点:周数据先 `aggregate_inc(daily, dt=7L)` 聚合,再 `estimate_R(incid, dt=7L, dt_out=7L, recon_opt="match")` —— 论文 Fig 2–4 均用 `recon_opt = "match"`。

## 五、Python 复现的验证结论

- 估计引擎对论文存储的 12 组 RDS 结果逐值一致到 **1e-14**;
- LOESS 移植对存储的 loess_rt.pdf 矢量曲线一致到 **<0.005 PDF 点**;
- 附录图输入(t_end 网格 + Mean(R))对存储 RDS 一致到 ≤4.5e-14;
- 模拟研究覆盖率与论文正文报告区间吻合(如突增 95.0/90.4/87.9% vs [87-96%]);
- 原 R 脚本中的多个 bug 及 EpiEstim 版本差异(distcrete vs discr_si 的 SI
  变体)已逐一查明,详见 [replication_notes.md](replication_notes.md);
- 小组统一参数约定(随机种子、时间索引、SI 参数、数组形状、输出字段等)见
  [CONVENTIONS.md](CONVENTIONS.md)(英文)。
